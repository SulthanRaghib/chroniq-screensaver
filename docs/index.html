Questions & Answers

Frequently Asked Questions

Is Chroniq Screensaver completely free?

Yes, Chroniq is 100% free with zero ads, telemetry, background tracking, or bloatware. Built with precision and care for pure desktop aesthetics.

What are the system requirements?

Chroniq runs on all versions of Windows 10 and Windows 11 (64-bit and 32-bit). No additional downloads or runtimes are required — it works out of the box on any modern Windows PC.

How do I uninstall Chroniq?

Run Chroniq_Setup.exe and click Copot (Uninstall), or run Uninstall_Chroniq.bat. All binaries and registry entries will be deleted completely.

Does it support multiple monitors?

Yes! Chroniq detects all active displays connected to your system and runs the screensaver synchronously across all monitors.

How do I install a downloaded .SCR file or bypass Windows SmartScreen?

When downloading executable screensavers (.SCR) from the internet, Windows browser protection may mark it. Simply right-click Chroniq.scr -> select Properties -> check Unblock -> click OK. Then right-click Chroniq.scr and choose "Install". Alternatively, download the Installer Package (.ZIP) and run the included 1-click batch script.

How does the OLED anti-burn-in feature work?

Chroniq automatically and gently shifts the clock's position by a few pixels every few minutes. This subtle, invisible movement prevents any single area of your screen from staying lit for too long — keeping your OLED or AMOLED display safe.
