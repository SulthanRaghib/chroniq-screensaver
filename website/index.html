Questions & Answers

Frequently Asked Questions

Is Chroniq Screensaver completely free?

Yes, Chroniq is 100% free, open-source, and contains zero ads, telemetry, or bloatware. You can view the entire source code on GitHub.

What are the system requirements?

Chroniq runs on all versions of Windows 10 and Windows 11 (64-bit and 32-bit). It requires .NET Framework 4.5 or newer, which is already built-in to Windows by default.

How do I uninstall Chroniq?

Simply delete Chroniq.scr from your C:\Windows\System32\ folder or wherever you saved it. There are no registry leftovers or background services.

Does it support multiple monitors?

Yes! Chroniq detects all active displays connected to your system and runs the screensaver synchronously across all monitors.

How do I install a downloaded .SCR file or bypass Windows SmartScreen?

When downloading executable screensavers (.SCR) from the internet, Windows browser protection may mark it. Simply right-click Chroniq.scr -> select Properties -> check Unblock -> click OK. Then right-click Chroniq.scr and choose "Install". Alternatively, download the Installer Package (.ZIP) and run the included 1-click batch script.

How does the OLED anti-burn-in feature work?

It calculates a periodic sub-pixel sinusoidal orbital offset. Every few minutes, the clock smoothly shifts position by 10–18 pixels, ensuring static pixel illumination is avoided.
